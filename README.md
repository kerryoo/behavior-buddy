# Behavior Buddy
A cross-platform desktop application for behavioral coding. Behavioral coding is the process of systematically observing and recording human behavior, often used in psychology, neuroscience, or behavioral science research. Researchers define specific behaviors (e.g. eye contact, verbal aggression, hand gestures).
While watching videos or live sessions, they "code" when those behaviors occur — usually by tagging timestamps with labels or scores.
This coded data is then analyzed to identify patterns, correlations, or outcomes in studies (like child development, therapy sessions, social interactions, etc.).

Behavior Buddy can be run to upload these test videos, code at specific time intervals, and export the data to a .csv file.
